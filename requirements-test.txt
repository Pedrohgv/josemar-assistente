# Local fast-test / pre-commit test environment dependencies.
#
# This file pins the THIRD-PARTY packages needed to run the repository's fast
# (non-Docker) unittest suite and pre-commit hooks in a local developer venv
# (see scripts/setup-pre-commit.sh and .github/workflows/fast-tests.yml).
#
# It is NOT production Docker dependency management. The Hermes runtime image
# (Dockerfile.hermes) and the aux-ml service (aux-ml/Dockerfile) install their
# own production requirements independently and are intentionally unaffected by
# this file. Do not add production runtime deps here.
#
# Pins are the versions validated for the fast-test suite (issue #91).
#
# mcp is pinned to mirror the Hermes runtime exactly. The runtime base image
# (Dockerfile.hermes: HERMES_BASE_IMAGE=nousresearch/hermes-agent:v2026.8.31,
# commit 29112bef099274229cadff79cdff7bf7b99c4b77) ships mcp==2.0.0 (verified
# from the built Josemar candidate image: docker run --rm
# --entrypoint /opt/hermes/.venv/bin/python3 <candidate-tag>
# -c "import importlib.metadata as m; print(m.version('mcp'))"),
# so the local pin mirrors the runtime exactly.
# Re-verify this pin whenever HERMES_BASE_IMAGE is bumped.
#
# Known limitation: mcp's own transitive dependencies are unpinned here, so
# reproducibility is top-level only (full lockfile reproducibility is out of
# scope for issue #91).
